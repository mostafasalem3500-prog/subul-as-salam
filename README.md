# سُبُل السلام · Subul as-Salam

منصة مجانية لتعليم **المسلم الجديد** بالسواحيلية والكينيارواندية والإسبانية. تأخذه من النطق بالشهادة إلى حفظ جزء عمّ والسنة، ويتابعه **مشرف تعليمي** يرى أين وصل، ونسبة تقدّمه، ودرجته في كل محطة.

> الاسم مأخوذ من سورة المائدة (الآية 16). في الموقع يُعرض نص الآية وترجمتها من QuranEnc، ولا يُكتب نص الآية يدويًّا في أي ملف.

| | |
|---|---|
| **الاستضافة** | GitHub Pages (ملفات ثابتة، بلا خادم) |
| **قاعدة البيانات والدخول** | Supabase: دخول بالإيميل، وصلاحيات RLS |
| **المحتوى** | IslamHouse API v3 · QuranEnc API · HadeethEnc API · رسالة الحرمين · مجمع الملك فهد |
| **المحتوى الدعوي** | مأخوذ من مشروع «رفيق الداعية» (الموقع الإسباني) |

## الميزات
- **صفحة أساسية لكل لغة** (`#/sw` و`#/rw` و`#/es`): يدخلها الطالب والمشرف. فيها بنك رسائل دعوية يكتبه فريق اللغة ويعتمده المدير.
- **12 محطة** من الشهادة إلى المستوى المتقدم، وكل محطة تُدرس بدورة يومية: اقرأ ← استمع ← احفظ ← طبّق ← قيّم.
- **صفحة الطالب بأربعة تبويبات** يراها الطالب ومشرفه:
  - **المنهج.**
  - **المتابعة.**
  - **المحادثات:** فورية، مع علامة القراءة.
  - **الاختبارات:** أسئلة اختيار ومقالية، وموعد شفهي، وتصحيح المشرف.
- **ربط المشرف بالطالب عبر الحساب،** بطلب ثم موافقة. ثلاث طرق: رابط الدعوة، أو الإيميل، أو رمز الإشراف.
- **لوحة المشرف:**
  - طلبات الربط.
  - جدول الطلاب، وتوزيعهم على المحطات.
  - الرسائل غير المقروءة.
  - تقييم كل محطة، وتوثيق التسميع.
  - بنك أسئلة، وتصدير CSV.
- **قارئ القرآن:**
  - الترجمة المعتمدة.
  - التلاوة آية آية مع التكرار.
  - وضع للحفظ يخفي الكلمات.
  - مستكشف لكلمات الترجمة.
- **اختبار آلي لكل محطة** يُبنى من الترجمة المعتمدة، بلا نص مولَّد.
- **ركن الداعية:**
  - كلمات دعوية موثّقة من ترجمات معاني القرآن.
  - من «رفيق الداعية»: دروس الداعية ودليله، و«اكتشف الإسلام»، والتحذيرات، وأسئلة الباحثين، و1000 رسالة إسبانية.
- **يعمل في وضع التجربة** قبل ربط Supabase، ويعمل دون اتصال للصفحات المفتوحة (PWA).

## الأمانة العلمية
- لا يُترجم أي نص شرعي من عندنا: كل آية وحديث وكتاب يُعرض كما هو من مصدره، مع اسم المترجم ورقم النسخة.
- نصوص الواجهة بالسواحيلية والكينيارواندية والإسبانية مسودة تحتاج مراجعة متحدث أصلي (`assets/js/i18n.js`).
- يُلتزم في الموقع بسياسة إعادة النشر في [بوابة المحتوى الإسلامي للمطورين](https://github.com/IslamHouse-API/multilingual-quran-hadith-islamic-content-database-api-hub).
